# ساعت‌کار عمو پرویز
نسخه اولیه PWA راست‌چین و فارسی.

## اجرا
برای آزمایش سریع، `index.html` را باز کنید. برای نصب PWA باید فایل‌ها را روی یک هاست HTTPS مانند GitHub Pages منتشر کنید.

## امکانات
ثبت و ویرایش/حذف شیفت، عبور از نیمه‌شب، کسر استراحت، نرخ ساعتی/روزانه، اضافه‌کاری، تاریخ شمسی (تقویم هجری شمسی)، پرداخت و مساعده، تاریخچه، CSV، چاپ/ذخیره PDF، پشتیبان‌گیری و بازیابی.

## محدودیت مهم
این نسخه اطلاعات را فقط در localStorage همین مرورگر نگه می‌دارد. همگام‌سازی دو گوشی و ورود مجزای مدیر/کارگر هنوز پیاده‌سازی نشده و برای آن به سرویس پایگاه داده و احراز هویت آنلاین نیاز است.
