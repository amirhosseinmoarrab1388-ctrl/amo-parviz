# سامانه مدیریت ساعت کاری

نسخه ارتقایافته PWA فارسی و راست‌چین.

## امکانات این نسخه
- نام اختصاصی فروشگاه و نام مدیر در تنظیمات
- خوشامدگویی روزانه برای مدیر یا پرسنل با جمله انگیزشی روز
- ثبت و ویرایش/حذف شیفت، عبور از نیمه‌شب و کسر زمان استراحت
- پیش‌نمایش مدت کار و مبلغ دستمزد هنگام وارد کردن ساعت شروع و پایان
- محاسبه نرخ ساعتی/روزانه و اضافه‌کاری
- پرداخت و مساعده
- ثبت پاداش پرسنل با وضعیت «در انتظار پرداخت» و امکان ثبت پرداخت در زمان بعد
- تاریخ شمسی در نمایش تاریخ‌ها
- تاریخچه، CSV، چاپ/ذخیره PDF، پشتیبان‌گیری و بازیابی
- انیمیشن‌های نرم دکمه‌ها و کارت‌ها و طراحی واکنش‌گرا
- امضای سازنده: AMIRHOSSEIN.MO

## انتشار روی GitHub Pages
فایل‌های این پوشه را در ریشه مخزن GitHub جایگزین نسخه قبلی کنید و Commit changes بزنید. سپس سایت را با بارگذاری مجدد کامل باز کنید.

## محدودیت‌های مهم
این نسخه همچنان داده‌ها را در localStorage همان مرورگر ذخیره می‌کند. انتخاب مدیر/پرسنل فقط نوع پیام خوشامدگویی را تغییر می‌دهد و امنیت یا سطح دسترسی واقعی ایجاد نمی‌کند. برای حساب‌های مجزا، محدودیت دسترسی و همگام‌سازی بین دستگاه‌ها به احراز هویت و پایگاه داده آنلاین نیاز است.
